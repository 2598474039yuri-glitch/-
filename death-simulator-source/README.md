# 等死模拟器｜源代码包

## 文件

- `index.html`：网页源码，包含页面结构、样式、模拟逻辑和事件数据。
- `assets/life-figures-sprite.png`：各年龄阶段小人的逐帧动画精灵图；需要与 `index.html` 保持相对目录结构。

## 本地运行

1. 解压本 ZIP，并保持 `index.html` 与 `assets` 文件夹的相对位置不变。
2. 用 Edge、Chrome 或其他现代浏览器打开 `index.html`。
3. 页面无需安装依赖，也无需运行构建命令。

成就和死法收藏默认保存在当前浏览器的本地存储中。同一浏览器配置文件可继续累计；清除网站数据、换浏览器或换设备后不会自动同步。网页不会通过 IP 登记玩家。

## 部署到互联网

这是静态网页项目。将 `index.html` 上传到任意支持静态文件托管的 Web 主机，并设置它作为站点首页即可运行。部署后建议通过 HTTPS 访问。

## 后续接入服务端的提示

当前版本不包含服务器、账号系统或网络 API。若要实现跨设备成就同步，可增加匿名玩家 ID 或账号登录，并通过 HTTPS API 将成就记录保存到服务端数据库；不要以 IP 作为玩家身份标识。

## 数据与说明

游戏页面内包含 WHO 统计改编后的模拟分布及游戏设定。模拟结果用于娱乐，不是对个人寿命或健康风险的预测。


## 模式切换
页面右上角可切换“默认真实模拟”“非自然死亡模拟”和“长生不死模拟”。非自然死亡模式使用本地死法池并在全部收集前不重复。年龄权重精确分配为 18% / 63% / 19%，再换算为存活者条件概率，最晚 120 岁结束；长生模式可通过“结束长生体验”手动结算；120 岁前故事每 2–4 岁更新，120 岁后每 10 岁更新。成就与非自然死法收集进度保存在当前浏览器的 localStorage 中。
